# 豐原區人口年齡結構、扶養負擔與性別差異

用臺中市豐原區 115 年 9 月的各里人口資料,看 36 個里的年齡結構、扶養負擔,以及男女在高齡人口上的落差。成果是一個可以互動篩選的 BI 網頁,雙擊就能開,也發佈在 GitHub Pages。

網頁:https://ichen0709.github.io/fengyuan-bi/

## 資料來源

- 臺中市政府民政局人口管理統計平台,「臺中市豐原區人口統計 - 表03-各區人口結構」
- 資料期間:115 年 9 月
- 分別下載性別「全部」「男」「女」三份 Excel 報表

## Repo 結構

```
raw/                     原始檔(平台下載的 Excel,未經修改)
  fengyuan_2026-09_population_all.xlsx      性別:全部(報表上標為「計」)
  fengyuan_2026-09_population_male.xlsx     性別:男
  fengyuan_2026-09_population_female.xlsx   性別:女
work/                    ETL 與資料整理程式,以及它們的輸出
  etl_population.py      把男、女兩份報表轉成整齊的長表 CSV
  population_115-09.csv  ETL 輸出(UTF-8 with BOM)
  build_data.py          把 CSV 整理成網頁用的 docs/data.js
scripts/
  validate_fengyuan.py   驗證 CSV 與三份原始檔是否一致
docs/                    網頁(GitHub Pages 從這裡發佈)
  index.html             單一檔案,圖表用 ECharts(從 CDN 載入)
  data.js                網頁載入的資料,由 build_data.py 產生
```

## ETL 流程

程式用 Python 寫,以 [uv](https://docs.astral.sh/uv/) 的 inline script metadata 宣告套件,不需要另外建立虛擬環境。

```
uv run work/etl_population.py                                  # raw/*.xlsx → work/population_115-09.csv
uv run scripts/validate_fengyuan.py work/population_115-09.csv # 驗證
uv run work/build_data.py                                      # work/population_115-09.csv → docs/data.js
```

1. **讀取**:原始報表只有一個工作表,第 2 列是合併儲存格的標題,第 3 列才是表頭。欄位是區域別、里名、性別、總計,後面是 0-4 歲到 95-99 歲,再加 100 歲以上。
2. **確認性別**:讀男、女兩份報表時,先檢查「性別」欄真的是男、女,不符就停止。
3. **去掉合計列**:里名為「全部」的列是整個豐原區的合計,不是一個里,不放進輸出,只用來驗證。
4. **轉成長表**:每一列是「里 × 性別 × 年齡組」,欄位為 `district, village, gender, age_group, age_min, age_max, count`,共 36 × 2 × 21 = 1512 列。
5. **年齡組**:去掉「合計」兩個字(「0-4歲合計」→「0-4歲」);「100歲以上」的 `age_max` 留空。
6. **保留 0**:人數是 0 的列也保留。

「全部」那份報表的性別是「計」,它是男加女的合計,只用於驗證。放進輸出會讓人數重複計算。

## 驗證項目

`scripts/validate_fengyuan.py` 全部通過時會印「全部通過」,有不符就列出是哪裡:

1. 里的數量是 36
2. 輸出筆數是 36 × 2 × 21 = 1512,gender 只有「男」「女」,沒有重複的「里 × 性別 × 年齡組」
3. 每個里、每個年齡組:男 + 女 = 「全部」那份的人數
4. 每個里:男、女各年齡組加起來,分別等於各自檔案的「總計」
5. 36 個里的男加起來等於男檔「全部」列的總計,女同理,男 + 女 = 160,762
6. 沒有負數、沒有空值(「100歲以上」的 `age_max` 依規則為空)

## 指標定義

年齡切法:0-14 歲是前 3 組,15-64 歲是中間 10 組,65 歲以上是 65-69 歲到 100 歲以上。

| 指標 | 公式 | 怎麼讀 |
|---|---|---|
| 老化指數 | 65 歲以上人數 ÷ 0-14 歲人數 × 100 | 越高,老年人相對於幼年人越多 |
| 扶養比 | (0-14 歲 + 65 歲以上)人數 ÷ 15-64 歲人數 × 100 | 每 100 位 15-64 歲的人要扶養多少位 |
| 性別比 | 男性人數 ÷ 女性人數 × 100 | 100 表示男女一樣多,低於 100 表示女性較多 |
| 老年性別比 | 65 歲以上男性 ÷ 65 歲以上女性 × 100 | 同上,只看 65 歲以上 |

分母為 0 時,指標存成 `null`,網頁顯示為「—」並從圖中略過。

全區的數字:總人口 160,762(男 78,592、女 82,170),老化指數 156.9,扶養比 48.2,性別比 95.6,老年性別比 80.8。

## 網頁功能

- 篩選列:里(多選)、最低人口數、指標、排序;改任一條件,四張圖同步更新。
- 四張圖:人口金字塔、各里指標排行、三階段人口組成、高齡的性別落差;每張都能切換圖型。
- 直接雙擊 `docs/index.html` 就能開,不用架伺服器。圖表程式庫要連網載入,沒有網路時頁面會顯示提示。

## 限制

- **單一月份**:只有 115 年 9 月,無法看趨勢。
- **5 歲一組**:年齡以 5 歲為一組,65 歲以上從 65-69 歲組起算,無法拆到單一歲數;三階段的切點(15 歲、65 歲)只能落在組界上。
- **小里不穩定**:人口少於 1000 人的里,比例與性別比容易受少數人影響。網頁的「最低人口數」可以排除這些里。
